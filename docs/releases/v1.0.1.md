# JingKong v1.0.1

界面与稳定性修复版。全部改动都在应用层，投屏协议、驱动与桥接组件无变化。

## 顶栏重做

- 投屏时顶部只保留居中的刘海/灵动岛，**移除常驻「停止投屏」按钮**——它正好压在 iOS 左上角「返回上一个应用」上，导致点不到。
- 全屏按钮从额头栏移除，最小化/关闭在投屏时折叠；两侧完全留空，状态栏的时间、返回面包屑、电量恢复可点。
- 所有操作统一收进悬停控制栏：停止投屏 ｜ 回到桌面 ｜ 全屏 ｜ 最小化 ｜ 关闭。
- 控制栏整体居中、宽度随内容，左右各留 16px；唤醒区从整条顶边收窄为「控制栏水平范围 + 额头栏高度」，指针离开即收起并恢复鼠标穿透。

## 启动与外观

- 窗口初始尺寸改为 340×700，首帧就是手机外壳，不再先闪一个 1040×720 的大黑窗。
- 待机态也按设备圆角曲线裁剪窗口（无设备时 28 DIP），直角黑边消失。
- 按机型显示刘海形态：SE / Home 键机型无刘海，iPhone X–14 贴顶刘海，14 Pro 起为灵动岛。
- 应用图标改为透明背景、10 个尺寸（16–256），去掉白底与「AI 生成」水印。

## 断链与延迟

- 视频静默阈值 2.5s → 4s，纯视频静默 5s → 7s，减少正常卡顿被误判成断流。
- 新增主机卡顿判别：USB 读取循环间隔超过 750ms 视为电脑被抢占，重置静默计时，不触发重连。
- 重连期间保持「可呈现」，不再销毁并重建渲染器，避免恢复后先画出十几秒前的旧帧。
- 新增「正在重新连接…」角标，说明是在恢复而不是卡死。
- 新增帧率 / 端到端延迟浮层（`receive_to_present` p50/p95）。开播先显示 10 秒，之后只在掉帧或 p95 ≥ 60ms 时出现。

## 其它

- 控制栏新增「回到桌面」，走不依赖前台焦点的发送通道；没有控制通道时给出明确提示。

## English

Maintenance release focused on the top chrome and connection stability. Protocol, driver and bridge components are unchanged.

- Mirroring header now shows only the centered notch/Dynamic Island. The always-on "Stop mirroring" pill was removed because it covered the iOS back-to-app breadcrumb; window buttons collapse while mirroring so both sides stay clear.
- All actions moved into a centered hover bar (stop, home, fullscreen, minimize, close) with 16px side margins. The wake-up zone is limited to the bar itself, so clicks on the status bar always reach the mirrored device.
- Window opens at 340×700 with the phone shell on the first frame; standby state is clipped to the device corner curve.
- Device-specific notch profiles: no notch on SE/Home-button models, top notch on iPhone X–14, Dynamic Island from 14 Pro.
- Transparent multi-size application icon without the white background.
- Reconnect thresholds raised to 4s/7s, host-stall detection added, renderer kept alive across reconnects so stale frames are no longer presented, plus a "Reconnecting…" badge.
- New FPS / end-to-end latency overlay that appears only when frames are dropped or p95 latency is at least 60ms.
- New "Home screen" action in the control bar.
