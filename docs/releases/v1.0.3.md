# JingKong v1.0.3

本版修复三个影响日常使用的问题：窗口四角变成小直角、副屏上顶部控制栏唤不出也拖不动、窗口尺寸抖动。

## 修复内容

### 1. 圆角丢失后不再恢复（大圆角消失）

窗口的大圆角依赖 `SetWindowRgn` 裁剪。旧版只在窗口尺寸变化时才重设，并且缓存了"上次设过的形状"——一旦系统或其它程序把窗口区域清掉，尺寸没变就不会再设，圆角从此变成 Windows 自带的 8px。

现在程序每秒校验一次窗口轮廓，并额外在窗口激活、DPI 变化、边框策略切换后补一次，被清掉后 1 秒内自动恢复，同时写一条 `shell_window_region action=restore` 日志便于定位触发时机。

另外窗口轮廓比画面圆角多留 2 DIP，四角的机身边框厚度更均匀，不会再出现"角上黑块比边上粗"。

### 2. 移到副屏后顶部控制栏失效

顶部悬停控制栏是一个独立浮层窗口，旧版用 WPF 的逻辑坐标跟随主窗口。主副屏缩放比不同时（例如 100% + 150%），浮层会被按自己那块屏的比例换算，整体偏到别处：鼠标移到窗口顶部唤不出控制栏，也就没有拖动把手。

现在浮层直接贴合主窗口的设备像素矩形，并按主窗口所在显示器的 DPI 换算高度，跨屏、跨缩放都对齐。

### 3. 投屏首帧窗口尺寸抖动

首帧到达时"面板高度 ↔ 窗口高度"会互相触发，窗口在两三像素之间来回改，每次都要重建 D3D 交换链。现在小于 1 DIP 的重复请求直接忽略。

## 升级方式

打开软件 → 检测到新版本 → 立即更新。也可以直接下载本页的 `JingKong-v1.0.3-win-x64.zip` 覆盖安装目录（保留 `%LOCALAPPDATA%\iPhoneMirror` 下的配置）。
